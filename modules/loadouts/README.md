# 改枪码

`/loadouts` 按《三角洲行动》官方枪名列出改枪码。码有两个来源：

- 已经采集的文章：正文里同时写了枪名和「改枪码 / 方案码 / 分享码」才会抽出来。
- 三个公开聚合站，由 worker 定时抓取（见下）。有力气的 anon key 有公开默认值，不需要另配密钥。

## 定时抓取

任务名 `loadouts.fetch`。只有 `COLLECT_ENABLED=true` 时才会排上，和信源采集用同一个开关。上海时间每 6 小时一次（`20 */6 * * *`）。请求走框架的 `guardedFetch`：配置了 `EGRESS_PROXY_URL` 就走出网代理，`.cn` 按框架规则直连。有力气的页面和 Supabase 表都不是 `.cn`：没设代理就直连（大陆能直接打开），设了就走代理。anon key 在请求头里，HTTPS 隧道过去，代理只看得到主机名。

每个站先读 `robots.txt`。云码库禁止 `/api/`，所以只抓公开 HTML，不调用它的接口。洲械库没有 robots 文件（任意路径都返回首页 HTML），按允许处理。有力气的 robots 允许全站；数据在 `*.supabase.co`，这个项目没有 robots.txt（404），按允许处理。两次请求之间停 1.2 秒。某个站回 403、429 或 503 时，这一轮不再翻它剩下的页。一个站失败不影响另一个；连续 5 次失败记为 `failing`，写在表 `loadout_feeds`（`health`、`last_error`、`note`），并进周一的信源健康报告和告警。任务本身的结果在后台运行记录 `loadouts.fetch`。刚抓完马上再抓一次，云码库会暂时 403/404，等下一轮即可。

| 站 | 抓什么 |
|---|---|
| 有力气 | 官方热门。`GET …/official_gun_codes?source=eq.official&is_hidden=eq.false&select=*&order=apply_num.desc`，请求头带公开 anon key。约 100 条，站点每天同步。码用 `solution_code`，枪名用码前缀，对不上再用 `arms_name`。模式在码里。作者是 `author_nickname`。价格是游戏币，写成「60.8万」。应用次数是 `apply_num`，写入 `popularity`，同枪的官方方案之间按它从高到低排。`synced_at` 换成北京时间的日期当发布日。下架（`is_hidden`）和非 `official` 的行不收。来源链到 `https://guns.yufantechs.com/official`。一次最多 1000 条，到顶会在 `note` 里警告。 |
| 云码库 | 首页，以及 `/loadouts?mode=` 的烽火地带、全面战场、黑潮爆破，按页面上的 `page=` 翻页。`heichao_loadout` 是国际服 BLAST 码，不抓。列表里很多条目只有码尾，对不上完整国服码，直接丢掉。 |
| 洲械库 | 首页 HTML，加上首页引用的 `/assets/page-*.js`。全量方案和发布日都在这个脚本里（`throughId` 区间，外加少量按 id 的日期）。脚本里站点自己藏起来的 id 不收。脚本抓失败时，仍保留首页已经渲染的那一页。 |

同一串码只留一条（`game_id + code`，整串国服码，不是行 id）。库里已经有的，后来的站不再覆盖作者和来源。同一轮里有力气先抓，所以这一轮新出现、别的站也有的码记成有力气。文章同步不会删掉聚合站的码，也不会改它的作者。

有力气的 anon key 是站点前端里的公开 `anon` 角色（到 2036 年），默认写在 `feeds.ts`。不在运行时再去扒打包脚本。轮换后设 `YUFAN_SUPABASE_ANON_KEY`，不设就用默认值。抓取返回 401 时改这个变量。

源站后来撤下的码，这里不会自动删。`shortcut: 不跟源站下架，要清旧码时再加一轮对账。`

## 什么码会留下

完整国服码，形如 `枪名-烽火地带|全面战场|黑潮爆破-` 再加至少 12 位字母数字。含 `Operations` 或 `Warfare` 的国际服码不要。枪名必须对上 `catalog.ts` 的官方枪；对不上的记在 `loadout_feeds.note` 里，不塞进别的枪。

有发布日、早于 `feeds.ts` 里 `SEASON_START` 的不新收录。没有日期的仍收录（云码库列表目前不给日期）。有力气用 `synced_at` 的北京时间日期：每天都在同步的热门方案落在本赛季；同步停在赛季开始日之前的，不新收录，已经入库的会在换季后标成过季。

## 改赛季日和主播名单

都在 `feeds.ts`。

- `SEASON_START`：当前国服赛季开始日（北京时间，含当天）。下一季「微光」从 **2026-11-05** 开始，到那天把这一行改成 `2026-11-05` 并重新构建、重启 worker。已经入库、发布日更早的码还在，页面上标「过季」，排在当前方案后面，不再当成当前配装。
- `PREFERRED_STREAMERS`：这些作者的方案排在同枪前面，并标「主播」。按包含关系匹配，`昊天` 对得上 `昊天（三角洲行动）`。改完重新构建即可，不用重抓。有力气的官方热门还排在主播前面，过季的仍然垫底。这是按来源排的，不用改这份名单。

页面上每条显示模式、价格、应用次数（有力气才有）、作者、来源站名和发布日（有的话），「来源」链回聚合站上的那一页或作者页。有力气显示成「有力气·官方热门」。
